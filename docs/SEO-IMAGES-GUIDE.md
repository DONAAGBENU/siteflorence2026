# Guide SEO - Images OpenGraph

## Fichiers à ajouter au dossier `public/`

Créez les images suivantes dans votre dossier `public/` :

### 1. **og-image.jpg** (1200x630px)
   - Image générale pour partage sur les réseaux
   - Dimensions: 1200x630px
   - Format: JPG ou PNG
   - Contient le logo et titre Fleur Sucrée

### 2. **og-home.jpg** (1200x630px)
   - Image spécifique pour la page d'accueil
   - Doit représenter l'essence de la marque

### 3. **og-products.jpg** (1200x630px)
   - Image spécifique pour la page produits
   - Montre des produits attrayants

### 4. **twitter-image.jpg** (1200x630px)
   - Image pour les partages Twitter/X
   - Peut être identique à og-image.jpg

### 5. **logo.jpg** ou **logo.png**
   - Logo de la marque
   - Format carré recommandé (500x500px minimum)

## Outils recommandés pour créer les images

1. **Canva** (https://www.canva.com/)
   - Modèles prêts à l'emploi
   - Interface simple

2. **Adobe Express** (https://www.adobe.com/express/)
   - Qualité professionnelle
   - Nombreux templates

3. **Figma** (https://www.figma.com/)
   - Pour designs personnalisés

## Optimisation des images

Utilisez ces outils pour optimiser vos images :

1. **TinyPNG** (https://tinypng.com/)
   - Compression sans perte
   - Supporte JPG et PNG

2. **ImageOptim** (https://imageoptim.com/)
   - Outil desktop
   - Optimisation avancée

3. **SVGO** (https://svgomg.firebaseapp.com/)
   - Pour les fichiers SVG

## Bonnes pratiques

✅ Dimensions exactes : 1200x630px pour OpenGraph
✅ Taille fichier < 300KB
✅ Formats : JPG (photos) ou PNG (designs)
✅ Texte lisible même en petit
✅ Incluez votre logo
✅ Utilisez les couleurs de votre marque
